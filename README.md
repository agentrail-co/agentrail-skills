# Agentrail skills

[Agent Skills](https://agentskills.io) that set up [Agentrail](https://www.agentrail.co)
and help you get more from it, in Claude Code, Codex, Cursor, GitHub Copilot,
Gemini CLI and any other agent that reads Agent Skills.

## Start here: set up Agentrail

**`agentrail-getting-started`** takes you from sign-up to a working setup, one
step at a time. You never have to work out what comes next. It reads your
Agentrail **Getting started** checklist, picks the next step that applies to
your product, does the work in your repository, and checks that the step
works before it moves on:

1. Your account and workspace
2. Connecting your coding agent to Agentrail (CLI or MCP)
3. Company research and your first agent readiness scan
4. GitHub
5. The edge, so every request is recorded, including agents that never run JavaScript
6. The browser script
7. The Node, Go or Python server SDK, with sign-in and MCP calls
8. Agent feedback, and a test report that proves it works

You do the clicks in the Agentrail web app; the agent does the code. Secrets
go straight into your secret store, never through the chat.

### Install it

```sh
npx github:agentrail-co/agentrail-skills
```

The installer asks three questions: which skills, every project or only this
one, and which agents (it finds the ones on your computer). It shows what it
will write, installs, checks every file, and tells you how to start the skill
in each agent. It needs Node.js 20 or later, copies files only, and sends
nothing anywhere.

Then open your agent in your project and say:

> Set up Agentrail

## Other ways to install

| Where                         | How                                                                                                         |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Any agent, without questions  | `npx github:agentrail-co/agentrail-skills install --agent detected --yes`                                   |
| Claude Code plugin            | `/plugin marketplace add agentrail-co/agentrail-skills`, then `/plugin install agentrail-getting-started@agentrail-skills` |
| The `skills` CLI              | `npx skills add agentrail-co/agentrail-skills`                                                              |
| Claude.ai or Claude Desktop   | Download [`agentrail-getting-started.zip`](https://github.com/agentrail-co/agentrail-skills/releases/latest/download/agentrail-getting-started.zip) and upload it under **Customize › Skills**. Code execution must be on. |
| By hand                       | Copy `skills/agentrail-getting-started` into one of the folders below.                                      |

Agents with their own skill installers (Codex's `$skill-installer`, Gemini
CLI's `gemini skills install`, the GitHub CLI's `gh skill install`, Amp's
`amp skill add`, Kiro's "Import skill") can install from the
`skills/agentrail-getting-started` folder of this repository.

## Where skills go

| Agent                                                                 | Every project            | One project         |
| --------------------------------------------------------------------- | ------------------------ | ------------------- |
| Claude Code                                                           | `~/.claude/skills`       | `.claude/skills`    |
| Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf, OpenCode, Goose, Amp | `~/.agents/skills`   | `.agents/skills`    |
| Cline                                                                 | `~/.cline/skills`        | `.cline/skills`     |
| Kiro                                                                  | `~/.kiro/skills`         | `.kiro/skills`      |

Some agents also read another agent's folder (Cursor reads `~/.claude/skills`,
for example), so a skill installed for both can be listed twice there. Both
copies are the same. Sources for every path are in
[docs/harnesses.md](docs/harnesses.md).

## Keep them up to date

```sh
npx github:agentrail-co/agentrail-skills list        # what is installed, and whether each copy is intact
npx github:agentrail-co/agentrail-skills update      # reinstall every copy at the newest version
npx github:agentrail-co/agentrail-skills uninstall   # remove the copies this installer made
```

The installer only updates or removes folders it made itself. It marks each
copy with an `.agentrail-skill.json` file, and leaves any other folder with
the same name alone.

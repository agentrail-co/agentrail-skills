# Connect GitHub (`github`)

Live guide: <https://www.agentrail.co/docs/guides/setup.md>

Connecting GitHub lets Agentrail read the repositories and open pull requests.
It is recommended, not required. An Admin does it in the browser, and the
person approving the GitHub App must be allowed to install apps on the GitHub
organization.

1. In <https://app.agentrail.co>, open **Integrations** in the sidebar.
2. On **GitHub**, select **Connect**.
3. GitHub asks which account and repositories to give access to. Choose the
   repositories for this product and approve.
4. GitHub sends them back to Agentrail.

## Check it

Read the checklist. `github` should be `done`.

- `attention` with `github_paused`: GitHub paused the connection, for example
  when the app was suspended or its permissions were removed. The Admin opens
  **Integrations** and connects it again.
- If they skip GitHub, say it stays on the checklist as recommended, and move
  on.

Research that already ran did not read the repositories. If research finished
before GitHub was connected, an Admin can select **Research again** on the
**Brand Vault** page so the Brand Vault includes them.
